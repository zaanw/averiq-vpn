# Averiq WireGuard API

Серверная часть для кнопки «Подключить iPhone» в Telegram Mini App.

## Что делает

- Проверяет подпись и срок действия Telegram WebApp initData на сервере по официальному алгоритму Telegram.
- Выдаёт каждому разрешённому Telegram ID отдельный случайный ключ WireGuard и случайный адрес из диапазона 10.66.66.10–10.66.66.254. Адрес .2 оставлен существующему клиенту.
- Сохраняет назначения в закрытой SQLite-базе и добавляет peer в активный wg0 и /etc/wireguard/wg0.conf. Повторные нажатия используют тот же профиль.
- Отправляет персональный файл Averiq-Karing.conf в личный чат Telegram через sendDocument. Приватный ключ не возвращается браузеру и не записывается в логи.
- По умолчанию доступ ограничен allowlist ALLOWED_TELEGRAM_IDS. Пока платежи не подключены, не открывай доступ всем пользователям.

## Установка на VPN VPS

Из корня клонированного репозитория выполни:

    bash backend/deploy.sh

На iPhone установи Karing из [App Store](https://apps.apple.com/app/karing/id6472431552). Karing поддерживает протокол WireGuard; после того как бот пришлёт файл Averiq-Karing.conf, открой его на iPhone и выбери импорт/открытие в Karing.

Скрипт запросит:
1. токен Telegram-бота (ввод скрыт; не вставляй его в GitHub или чат);
2. точный HTTPS origin Mini App, например https://example.com или https://zaanw.github.io — без пути и завершающего слеша;
3. Telegram ID, которым разрешено получить конфиг (можно указать список через запятую);
4. IP/домен WireGuard (по умолчанию 79.137.184.71).

Секреты сохраняются в /etc/averiq-api.env с правами 600. База с приватными ключами находится в /var/lib/averiq-api/clients.sqlite3 с закрытыми правами. Сервис слушает только 127.0.0.1:8765.

## HTTPS и подключение сайта

Telegram Mini App работает по HTTPS. Не открывай порт 8765 в интернет и не указывай HTTP URL. Настрой HTTPS reverse proxy на HTTPS-домене API, либо проксирование /api/* на том же домене, где раздаётся Mini App.

После настройки проверь локально на VPS:

    curl -fsS http://127.0.0.1:8765/health

Должен вернуться JSON: {"ok": true}.

В index.html есть метатег:
    <meta name="averiq-api-base" content="">

- Если прокси обслуживает /api/* на том же origin, оставь content пустым.
- Если API на отдельном домене, укажи полный HTTPS origin, например content="https://api.example.com". Также добавь origin Mini App в ALLOWED_ORIGINS и перезапусти averiq-api.

Сейчас Xray может занимать TCP-порт 443 на VPN VPS. Перед привязкой Caddy/Nginx к 443 на этом же сервере проверь занятость порта. Возможно, нужно перенести/остановить Xray или использовать отдельный API-хост. Не останавливай Xray вслепую, если он ещё нужен.

## Проверка и обслуживание

    systemctl status averiq-api --no-pager
    journalctl -u averiq-api -n 50 --no-pager
    wg show wg0

У каждого пользователя один профиль. Повторная выдача отправляет тот же файл. Allowlist временный; до публичного запуска подключи проверку платёжного статуса, чтобы только активные подписчики получали VPN.

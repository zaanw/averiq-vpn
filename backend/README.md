# Averiq WireGuard API

Серверная часть Telegram Mini App для выдачи персональной конфигурации WireGuard.

## Что делает

- Проверяет подпись и срок действия Telegram WebApp initData на сервере.
- Выдаёт каждому разрешённому Telegram ID отдельный случайный ключ WireGuard и случайный адрес из диапазона 10.66.66.10–10.66.66.254.
- Сохраняет назначения в закрытой SQLite-базе и добавляет peer в активный интерфейс WireGuard и конфигурацию сервера. Повторные запросы используют тот же профиль.
- Отправляет персональный файл `Averiq-WireGuard.conf` в личный чат Telegram через `sendDocument`. Приватный ключ не возвращается браузеру и не записывается в логи.
- По умолчанию доступ ограничен allowlist `ALLOWED_TELEGRAM_IDS`. Платёжная проверка пока не реализована, поэтому не открывай доступ всем пользователям.

## Установка на VPN VPS

Из корня клонированного репозитория выполни:

    bash backend/deploy.sh

Скрипт запросит:
1. токен Telegram-бота (ввод скрыт; не вставляй его в GitHub или чат);
2. точный HTTPS origin Mini App, например `https://example.com` — без пути и завершающего слеша;
3. Telegram ID, которым разрешено получить конфиг;
4. IP/домен WireGuard.

Секреты сохраняются в `/etc/averiq-api.env` с правами `600`. База с приватными ключами находится в `/var/lib/averiq-api/clients.sqlite3` с закрытыми правами. Сервис слушает только `127.0.0.1:8765`.

## HTTPS и подключение сайта

Telegram Mini App работает по HTTPS. Не открывай порт 8765 в интернет и не указывай HTTP URL. Настрой HTTPS reverse proxy на домене API либо проксирование `/api/*` на том же домене, где раздаётся Mini App.

Проверь локально на VPS:

    curl -fsS http://127.0.0.1:8765/health

Должен вернуться JSON:

    {"ok": true}

В `index.html` есть метатег `averiq-api-base`:
- Если прокси обслуживает `/api/*` на том же origin, оставь значение пустым.
- Если API на отдельном домене, укажи полный HTTPS origin и добавь origin Mini App в `ALLOWED_ORIGINS`, затем перезапусти `averiq-api`.

Перед привязкой Caddy/Nginx к порту 443 проверь, не занят ли он Xray. Не останавливай Xray вслепую, если он ещё нужен.

## Проверка и обслуживание

    systemctl status averiq-api --no-pager
    journalctl -u averiq-api -n 50 --no-pager
    wg show wg0

## Перед публичным запуском

Текущая версия **не принимает оплату и не активирует подписки автоматически**. До подключения платёжного провайдера оставь allowlist включённым.

Для платного запуска необходимо добавить серверную проверку платёжных уведомлений, сверку заказа и суммы, хранение срока подписки, выдачу конфигурации только активным подписчикам и отключение peer после окончания доступа. Не активируй доступ по скриншоту, параметру из браузера или сообщению пользователя.

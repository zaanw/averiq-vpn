# Averiq VPN

## Автоматическая выдача доступа

Первая интеграция платежей использует **ЮKassa + СБП**. Тариф в коде фиксирован: 499 ₽ за 30 дней.

### Поток оплаты

1. Пользователь открывает Mini App в Telegram и выбирает Karing или WireGuard.
2. Backend создаёт платёж ЮKassa на 499 ₽ с методом оплаты СБП.
3. Пользователь завершает оплату в платёжной форме/приложении банка.
4. ЮKassa отправляет `payment.succeeded` на `https://<API-домен>/api/webhooks/yookassa`.
5. Backend повторно запрашивает платёж у ЮKassa и сверяет статус, сумму, валюту, способ оплаты и заказ.
6. Только после подтверждения подписка активируется на 30 дней; бот отправляет персональную ссылку на скачивание конфигурации.
7. Ссылка перестаёт работать по окончании подписки. Фоновая задача удаляет просроченный WireGuard peer и его блок из конфигурации сервера.

### Настройка

1. Подготовь публичный домен для API и настрой HTTPS на нём. API должен проксировать пути `/api/*` и `/s/*` на `127.0.0.1:8765`. Не открывай порт 8765 в интернет.
2. В кабинете ЮKassa создай магазин и получи Shop ID и Secret Key. Начни с тестового режима.
3. На VPS запусти от root: `bash backend/deploy.sh`. Скрипт запросит Telegram Bot Token, разрешённый origin Mini App, тестовые Telegram ID, API URL, URL Mini App и реквизиты ЮKassa. Секретный ключ вводится скрыто и сохраняется только в `/etc/averiq-api.env` с правами доступа 600.
4. В настройках HTTP-уведомлений ЮKassa укажи `https://<API-домен>/api/webhooks/yookassa` и событие `payment.succeeded`.
5. В `index.html` установи `content` у meta `averiq-api-base` равным API URL, например `https://api.example.com`. Это URL API, не URL Mini App.
6. Убедись, что reverse proxy передаёт `/api/payments/create`, `/api/webhooks/yookassa` и `/s/<персональный-токен>` в локальный API.
7. Перезапусти службу: `systemctl restart averiq-api`; проверь `systemctl status averiq-api` и `journalctl -u averiq-api -n 100 --no-pager`.

### Важные ограничения

- Не добавляй Bot Token, Secret Key, клиентские private keys или персональные ссылки в GitHub.
- Уведомление об оплате не считается достаточным доказательством само по себе: backend проверяет платёж отдельным запросом к API ЮKassa.
- Персональная ссылка в этой версии скачивает WireGuard-конфигурацию. Это не автоматически обновляемая подписка для прокси-протоколов; Karing импортирует WireGuard-профиль, а полноценная подписка с автообновлением потребует совместимого протокола и отдельной реализации.
- Перед приёмом реальных платежей проверь тестовую оплату, повторную доставку webhook, отменённый платёж, повторную покупку и истечение срока.

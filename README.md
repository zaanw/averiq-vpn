# Averiq VPN

Averiq — небольшой VPN-проект с Telegram Mini App и WireGuard. Репозиторий содержит веб-интерфейс и API для выдачи персональных конфигураций WireGuard.

## Текущий статус

**Разработка продолжается. Публичные платные подписки пока не запущены.**

| Возможность | Статус |
|---|---|
| Интерфейс Telegram Mini App | Есть |
| Серверная проверка Telegram WebApp initData | Есть |
| Создание отдельного WireGuard-профиля | Есть |
| Отправка конфигурации в Telegram | Есть |
| Реальная оплата через СБП | Не подключена |
| Проверка платежа и автоматическая активация тарифа | Не реализована |
| Автоматическое отключение по окончании подписки | Не реализовано |
| Публичный запуск для всех пользователей | Не готов |

Пока платёжная интеграция не завершена, интерфейс оплаты является демонстрационным. Не принимайте деньги за тариф через текущую страницу.

## Структура

- `index.html` — интерфейс Mini App.
- `backend/app.py` — API для проверки Telegram и выдачи конфигураций WireGuard.
- `backend/deploy.sh` — скрипт установки API на VPS.
- `backend/averiq-api.service` — unit-файл systemd.
- `backend/README.md` — инструкция по установке и настройке API.

## Как сейчас работает подключение

1. Пользователь открывает Mini App из Telegram.
2. API проверяет подпись и время действия данных Telegram.
3. Сервер создаёт или восстанавливает персональный peer WireGuard для разрешённого Telegram ID.
4. Бот отправляет конфигурацию пользователю в личный чат.

До подключения платежей доступ следует ограничивать списком разрешённых Telegram ID. Не включайте публичную выдачу конфигураций всем пользователям.

## Что требуется до платного запуска

1. Вместе с родителем или законным представителем выбрать платёжного провайдера и подтвердить, что он разрешает принимать оплату за VPN-доступ и работать с выбранной моделью продаж.
2. Оформить аккаунт продавца и выполнить требования провайдера по идентификации, чекам и налогам.
3. Реализовать создание заказа и платёжной ссылки для СБП на сервере.
4. Проверять подпись уведомлений провайдера, сумму, валюту, номер заказа и повторную доставку уведомлений. Не активировать подписку по скриншоту или нажатию пользователя.
5. Хранить статус подписки и даты её действия на сервере; выдавать конфигурацию только при активном доступе.
6. Реализовать истечение подписки, отключение WireGuard peer, возвраты и обработку неуспешных платежей.
7. Проверить сценарии оплаты и выдачи доступа в тестовом режиме, прежде чем принимать реальные деньги.

## Безопасность

- Не добавляйте токены Telegram, секреты платёжного провайдера, приватные ключи WireGuard или содержимое конфигураций в Git.
- Храните секреты в переменных окружения или файле конфигурации с ограниченными правами.
- Платёжные уведомления должны проверяться на сервере; фронтенд не является источником истины об оплате.
- Перед публичным запуском проверьте ограничения доступа, журналы, резервные копии и восстановление сервера.
